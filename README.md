# 🌸 Iris Classification Project

## 📌 Overview

This project is an educational machine learning project aimed at understanding how ML algorithms work in practice.

It uses the scikit-learn library to train a classification model that predicts the species of iris flowers based on input features.

---

## 🎯 Goal

The goal of this project is to:
- Learn the basic ML workflow
- Train a simple classification model
- Allow user input for real-time predictions

---

## 📊 Dataset

The project uses the built-in Iris dataset from scikit-learn:
- 150 samples
- 3 classes (Setosa, Versicolor, Virginica)
- 4 features:
  - sepal length
  - sepal width
  - petal length
  - petal width

---

## 🤖 Model

A Random Forest Classifier is used because:
- It is stable and accurate
- Works well on small tabular datasets
- Requires minimal preprocessing

---

## 🚀 How to Run

### 1. Install dependencies
```bash
pip install -r requirements.txt
```
### 2. Run the program
```bash
python main.py
```
### 3. Enter values when prompted
```bash
5.1, 3.5, 1.4, 0.2
```
